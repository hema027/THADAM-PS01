# CloneTrace Brand Gallery Reference Data

These screenshots and metadata files represent synthetic canonical gallery references
for the 6 supported brands (PhonePe, Paytm, Google Pay, BHIM, SBI, and HDFC).
They serve as visual baselines for perceptual hashing (pHash/dHash) and visual
similarity scoring. Real brand screenshots can be dropped in directly into each brand
folder at any time without requiring code changes.
